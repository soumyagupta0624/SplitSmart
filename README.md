# SplitSmart 💸

A shared expense splitter built using Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Create and switch between multiple groups
- Add members to each group
- Record shared expenses
- Split expenses among selected participants
- Calculate balances between group members
- View recent expenses
- Calculate settlements to simplify who owes whom

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Tools:** VS Code, Git, GitHub

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/soumyagupta0624/SplitSmart.git
   ```

2. Open the project folder:
   ```bash
   cd SplitSmart
   ```

3. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:
   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.
